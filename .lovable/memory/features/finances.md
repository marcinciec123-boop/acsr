---
name: Team finances
description: Org finance rules — income/cost sources, manual entries, warnings only, manual bankruptcy
type: feature
---
Income: 25% of tournament prizes, transfer buyouts received, manual entries (e.g. CEO funding).
Costs: salaries, signing bonuses, buyouts paid, monthly running costs (marketing, events), manual expenses.
User has FULL control: never auto-sell, auto-disband or auto-bankrupt. Only show warnings (low / negative / far below zero). Bankruptcy only via manual button with confirmation.
Starting budget and monthly running cost are editable per team.
